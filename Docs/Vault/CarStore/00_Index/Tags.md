# Tag Catalog

Authoritative list of tags used across the CarStore vault. Read this file live before tagging any note — never hard-code a cached copy elsewhere.

## Tag catalog

### type/*

- `type/overview` — high-level summary of a folder or area
- `type/index` — navigation/tag/glossary index note
- `type/guide` — how-to or engineering guide
- `type/runbook` — operational step-by-step procedure
- `type/reference` — external documentation or link summary, or a factual entity/API reference note
- `type/template` — note template

### area/*

- `area/architecture` — solution layering and structure
- `area/domain` — domain entities and business rules
- `area/engineering` — code style and conventions
- `area/operations` — build, run, test procedures
- `area/project` — repository layout, dependencies, and project-level facts

### component/*

- `component/domain` — `CarStore.Domain`
- `component/application` — `CarStore.Application`
- `component/web` — `CarStore.Web`
- `component/tests` — `CarStore.Tests`

### entity/*

- `entity/brand` — `Brand` domain entity
- `entity/car` — `Car` domain entity
- `entity/customer` — `Customer` domain entity

### Base

- `note` — applied to every note in the vault
